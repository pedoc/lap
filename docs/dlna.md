# DLNA 投放与共享

Lap 支持两种方式，均可选择“所选内容”或“整个相册（包含子目录）”作为范围：

- **主动投放**：在 Lap 选择电视，由 Lap 控制播放。
- **电视主动浏览**：Lap 发布媒体服务器，电视用遥控器浏览共享内容并选择播放。

## 使用方法

1. 将电脑与电视连接到同一局域网。
2. 选中一张或多张照片、视频，右键选择“DLNA 投放与共享”；查看器工具栏也提供相同入口。相册右键另有“投放整个相册到电视…”和“让电视浏览此相册…”入口。
3. 在窗口中选择“所选内容”或“整个相册”，再选择连接方式。
4. **主动投放**：开启电视的 DLNA 接收功能，选择搜索到的电视并点击“投放”。电视需要提供 MediaRenderer / AVTransport 服务。可以上一项、下一项及暂停视频；开启“连续播放”后，照片按所选间隔切换，视频在接收端报告结束后切换。整相册默认开启连续播放，播放到最后一项后停止自动切换。
5. **电视主动浏览**：点击“开始共享”，在电视的“媒体服务器／家庭网络”中找到 `Lap · 相册名`（或 `Lap · 所选内容`），进入共享内容后自行选择播放。此模式需要电视提供 DLNA 媒体浏览功能，无需电视支持被其他设备主动控制。
6. 点击“停止投屏／停止共享”或关闭窗口即可结束共享。切换图库、关闭所属窗口也会撤销会话。

## 网络与顺序

- 主动投放默认依次搜索所有已连接、支持组播的局域网 IPv4 网卡。也可在“搜索网络接口”中选择一张网卡；界面显示搜索进度，设备旁标出来源网络。停止搜索后可以选择已经找到的设备。
- 整相册默认使用当前 Lap 视图的排序与分组设置，并保留本次视图的随机种子。也可改为拍摄时间、文件名、标题、导入顺序或随机顺序；非随机自定义排序支持升序和降序。
- 所选内容默认保留传入的选择顺序。投放队列在开始时固定；更改顺序需要停止后重新开启。
- 电视主动浏览会在系统默认联网网卡发布媒体服务器，界面显示发布网络和实际地址。它不需要先搜到电视；电视端在“媒体服务器／家庭网络”中发现 Lap 后浏览和播放。
- 电视端默认浏览使用所选目录顺序；若电视明确请求按标题等字段排序，则遵循电视端的排序请求。

## 格式与范围

- 照片使用 Lap 的本地解码能力，生成适配 4K 屏幕的 JPEG 预览，并应用照片方向和图库旋转。不会修改原文件。
- 视频使用原始文件和编码，通过 HTTP Range 按需读取。电视需要支持相应的容器与音视频编码；首版不提供自动视频转码。
- 搜索与媒体传输使用 IPv4。电脑与电视需要可以直接通信，访客网络、无线客户端隔离、VPN 路由或防火墙可能影响发现和播放。Windows 如出现防火墙提示，可允许 Lap 访问专用网络。
- 共享范围采用开始时的媒体列表快照。新增文件需停止后重新开启共享；隐藏、删除和排除状态会在目录和媒体访问时重新检查。
- 媒体目录支持分页、标题排序、元数据查询及事件订阅。电视请求完整目录时，响应使用自动删除的临时文件流式生成，避免把整个相册的 XML 同时放入内存。
- 此功能展示照片和视频，不提供屏幕镜像或音量控制。
- 接收端需要支持相应操作。界面显示“已发送播放请求”表示电视接受了控制请求，实际是否解码显示仍由接收端决定。

## 媒体访问

主动投放仅接受所选电视 IP 的连接，并只提供当前一项内容。电视主动浏览会通过 SSDP 发布 MediaServer、ContentDirectory 和 ConnectionManager 服务，同一局域网设备均可发现并浏览所选范围；其他图库内容不会公开。它使用 IPv4 的 UDP 1900 端口进行发现、动态 HTTP 端口传输媒体，Windows 防火墙需要允许 Lap 访问专用网络。

URL 使用会话随机票据，且每个请求必须属于本次共享范围。视频分块读取，不会将完整视频装入内存；照片按需生成 JPEG，并只缓存最近一项预览。媒体服务在停止时撤销访问和发现公告。

隐藏、已删除、原文件不可用或仅在云端的媒体不能投屏。访问时会重新检查图库、可见性和原文件状态；播放期间也会定期复查。停止时会先撤销媒体访问；主动投放还会尝试通知电视停止播放，电视浏览模式则撤销发现公告和媒体服务。已被电视接收或缓存的画面无法从接收端收回。
