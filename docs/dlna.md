# 投放到电视（DLNA）

Lap 可以作为 DLNA 控制端，将选中的照片或视频投放到同一局域网中的电视、电视盒子或其他媒体接收端。

## 使用方法

1. 将电脑与接收端连接到同一局域网，并开启接收端的 DLNA / 媒体渲染功能。接收端需要提供 UPnP MediaRenderer 与 AVTransport 服务。
2. 在 Lap 中选中一张或多张照片、视频，右键选择“投放到电视（DLNA）”。查看器工具栏也提供相同入口。
3. 选择搜索到的接收端，点击“投放”。多选内容可以用“上一项”“下一项”切换，视频可以暂停或继续。
4. 点击“停止投屏”或关闭投屏窗口即可结束媒体共享。切换图库、关闭所属窗口也会撤销会话。

## 格式与范围

- 照片使用 Lap 的本地解码能力，生成适配 4K 屏幕的 JPEG 预览，并应用照片方向和图库旋转。不会修改原文件。
- 视频使用原始文件和编码，通过 HTTP Range 按需读取。电视需要支持相应的容器与音视频编码；首版不提供自动视频转码。
- 搜索与媒体传输使用 IPv4。电脑与电视需要可以直接通信，访客网络、无线客户端隔离、VPN 路由或防火墙可能影响发现和播放。Windows 如出现防火墙提示，可允许 Lap 访问专用网络。
- 这是由 Lap 选择内容并控制电视播放的功能；尚未提供电视端浏览整个图库的 DLNA 媒体目录、屏幕镜像、自动轮播或音量控制。
- 接收端需要支持相应操作。界面显示“已发送播放请求”表示电视接受了控制请求，实际是否解码显示仍由接收端决定。

## 媒体访问

媒体服务仅在投屏会话期间监听通往所选电视的本机网络地址，且只接受该电视 IP 的连接。URL 使用随机票据，只提供当前选中的一项内容；切换项目会使上一项的 URL 失效。视频分块读取，不会将完整视频装入内存。

隐藏、已删除、原文件不可用或仅在云端的媒体不能投屏。访问时会重新检查图库、可见性和原文件状态；播放期间也会定期复查。停止会话时先撤销媒体访问，再尝试通知电视停止。已被电视接收或缓存的画面无法从接收端收回。
