# 媒体访问统计

访问统计仅保存在当前图库数据库，从支持此功能的版本开始累计，无法补算以前的查看次数。不上传访问数据，不修改原图、EXIF、真实文件时间、评分或 AI 索引，也不保存逐次访问日志。

## 计数口径

- 在活动窗口中主动打开图片、RAW 或视频，内容准备好并连续查看至少 1 秒，记一次访问。
- 快速掠过、缩略图加载、首页轮播、自动幻灯片以及未激活的对比图片不计数。
- 同一打开期间，元数据刷新、缩放、旋转、焦点恢复或 RAW/JPEG 显示切换不重复累计。主动切到其他图片再返回，或者关闭后重新打开，属于新的访问。
- 视频循环播放不会重复计数；停止幻灯片后继续主动查看当前图片可以计数。
- 计数通过原子 SQL 更新，多窗口同时查看不会丢失增量。已经移入回收站的条目不新增访问；恢复后保留既有统计。

## 查看和使用

- 信息面板展示“访问次数”和“最近查看”；没有记录时显示“尚无查看记录”。独立看图窗口也可通过信息按钮或 `I` 查看。
- 排序支持访问次数、最近查看；设置中的缩略图上下标签也可选择这两项。
- 组合筛选和智能相册支持访问次数比较、次数范围，以及最近查看的日期条件。例如访问次数等于 `0`，或最近 7 天查看过。
- 首页“经常查看”展示最多 6 张正常可见的照片／RAW，按访问次数、最近查看时间排序；“查看全部”打开同一范围的排序结果。隐藏图片、回收站和组合媒体的配套文件不进入该区域。

多窗口会就地同步已加载条目的统计，不整页刷新或重置滚动位置。当前浏览列表不会因为访问次数改变而突然重排或移走正在看的图片；新的排序、筛选和查询使用最新数据。统计随图库数据库备份保存，重扫和元数据刷新不会清零。
