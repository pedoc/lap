# 识别功能交互优化

沿用现有模型与派生索引，不修改原始媒体，不重启运行中的后端。每项增加回归测试、独立本地提交，不自动推送。

- [x] U01：人脸复核收到后台更新时保留当前选择、输入和预览，提供明确的更新入口。
- [x] U02：对象修订和模型配置增加未保存保护，刷新、切换和取消不能静默丢失草稿。
- [x] U03：OCR 标记框支持就地修改、忽略和保存，保留原有全文修订入口。
- [x] U04：明确模型测试会保存配置，避免按钮名称掩盖持久化行为。
- [x] U05：智能相册补充 OCR／对象索引覆盖、缺失模型、待处理／失败和操作引导。
- [x] U06：对象忽略误报后保留框旁确认位置，可就地保存、取消或撤销忽略。

验证区分源码／隔离组件测试、生产构建和原生窗口交互。尚未完成原生验收的项目不得标为实机通过。

## U01

- 后台更新只提示有新结果，不重建复核列表，不清空选择、姓名输入、预览和框旁编辑。
- 主动刷新有未提交的批量操作时先确认；刷新期间到达的新通知不会被旧查询消除。
- 人脸复核 20 项回归通过，包含 100 次后台通知保持草稿与零额外列表查询。原生窗口待验收。

## U02

- 对象编辑建立原始快照；有未保存修改时，开始另一张图的修订需明确确认。取消保留旧草稿，保存中不能覆盖；较晚的确认不能清掉新草稿或作用到已切换的图库／照片。
- 单纯浏览其他照片不再误判为源文件变化；返回原图后重新校验源摘要、模型和修订，真实变化仍阻止保存。
- 模型参数和 API 密钥在后台刷新时保留；切换配置模型、任务、设置页签或关闭设置窗口先确认。普通 Tab 恢复表单焦点导航，Ctrl+Tab 才切页。
- 对象／模型／下载／OCR 相关 110 项回归通过，涵盖取消、迟到响应、草稿返回和保存中保护。原生窗口待验收。

## U03

- 单击文字框打开框旁单行修订，不触发图片缩放；支持改字、忽略、恢复原文、保存及取消。原有全文修订保留。
- 忽略和空白行会从有效文档移除，框的显示行号不等于原始修订下标；通过原始行顺序、有效文字和几何校验定位，再保存完整修订向量，保留源摘要与版本保护。
- 面板与对象修订共用边界定位，随图片变换调整锚点，保持正向。切图／换模型后阻止旧草稿写入，关闭或切换文字行先确认未保存修改；保存失败保留输入。
- OCR 增强与工作区 38 项回归及生产构建通过，包含真实编译模板和框点击逻辑；原生窗口点选／输入仍待验收。

## U04

- 测试按钮明确改为「保存并测试」，补充先保存参数／密钥、测试失败不回滚已保存配置、在线请求仍需授权的说明。
- 不增加临时测试后端或更改在线上传授权，避免中断正在运行的后端。模型配置相关回归通过。

## U05

- 智能相册浏览与规则预览按实际依赖显示 OCR／对象索引覆盖、待识别和失败数量、模型缺失、任务进度和停止入口；空结果自动展开说明，不把未识别当成没有文字／对象。
- 可就地打开相应模型配置，或显式确认后处理当前图库待识别／失败照片；确认明确是图库范围而非仅此相册，不强制重建、不自动下载或切换模型。
- 只挂载规则使用的识别能力，不为普通条件或未使用能力额外轮询。切库／换模型后的旧确认不会启动任务。
- 智能相册相关 45 项回归通过，包含实际模板与动作保护；原生界面待验收。

## U06

- 忽略误报改为可撤销的草稿状态：框以半透明虚线保留，选中状态及框旁面板不消失，保存／取消不再跳到顶部；可在原位撤销忽略。
- 保存时才从提交文档中剔除忽略框；草稿标志不写入持久化对象。保存失败仍保留面板、原选择和待忽略状态，取消不会改变原检测结果。
- 对象组件回归覆盖实际编译事件的忽略→撤销→保存、并发版本保护及保存失败。U01–U06 的实现／隔离回归已完成，不代表原生窗口验收完成。
