# 图库补齐任务单

## 范围与执行约定

- 不修改原始媒体的 EXIF／IPTC／XMP，不做元数据写回、批量日期／时区／GPS 修正。
- 不做云分享、多用户或手机上传，不自动清空回收区。
- 可以读取已有旁文件，移动／恢复时仅保留其原始内容；这不是元数据编辑。
- 每项独立实现、增加回归测试、验证后更新本任务单并自动提交；提交信息包含任务编号。只提交该项涉及的文件，不自动推送。
- 原文件、评级、标签、集合关系及人工人脸标注优先保全。未完成和未实机验收的工作不得标为完成。

## 验证与记录

前端：`pnpm build`，Node 全量测试及实际 Vue 模板／交互回归。
后端：相关 Rust 回归和全量测试。文件测试只使用工作区内自建临时文件，禁止针对用户原照片做破坏性试验。
另需安排 NTFS、exFAT／网盘、掉盘、空间不足等环境验收；自动化测试不能替代真实桌面点击验收。

每项完成记录包含验证结果和限制；提交哈希通过 `git log --grep=Txx` 查阅，避免在提交自身之前伪造哈希。
