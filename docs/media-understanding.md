# 媒体理解、Embedding 与自然语言检索

本功能通过用户配置的 OpenAI 兼容 API 工作。现有 CLIP 语义检索、人脸、OCR 和对象识别继续使用原有模型与索引。

## 配置 Embedding

1. 打开现有的独立设置窗口，进入 **AI 模型 → 媒体理解**。
2. 点页签顶部的 **配置 Embedding**，或在“默认用途”的“文本 Embedding”右侧点 **配置**。
3. 选择已有服务或新服务，填写 API 基础地址、API Key 和服务端 **Model ID**。
4. 选择查询编码预设。部署脚本的 `qwen3-embedding-0.6b` 使用 **Qwen3 Embedding**；其他模型按其文档选择普通文本或自定义查询指令。正文不添加查询指令。
5. 勾选传输许可，点 **检测**。应用分别编码一段测试正文和一条查询，检查数量、index、实际维度、有限数值及非零向量。无需提供聊天接口。
6. 点 **保存并设为默认 Embedding**。保存会再次检测，成功后才同时保存服务、模型、检测结果和默认绑定。失败不留下半成品配置。

基础地址示例：`https://embedding.example.com/v1`。不要填写 `/embeddings` 或 `/chat/completions` 完整路径。基础地址保留网关前缀；非回环地址要求 HTTPS。本机 API 或 SSH 转发可使用 `http://127.0.0.1:8002/v1`。

API Key 存入系统凭据库，不进入 JSON、数据库或备份。留空保留原密钥；移除密钥请用“清除已保存密钥”。修改地址后需要重新输入或显式清除旧密钥。服务名称与部署平台无关。

## 配置媒体理解和文本生成

在同一个页签添加服务，获取模型列表或手动添加 Model ID。列表只用于发现模型，不证明模型具备对应能力。

“获取模型”后先勾选需要的模型，再点“添加选中”；未勾选的模型不会加入配置。已配置模型标题右侧的移除按钮始终可用，无需展开模型。移除后点击“保存”生效；对应默认用途会解除绑定，已生成的分析和索引保留。再次获取列表不会自动加回已移除模型。

为模型勾选实际能力并分别检测：

| 能力 | 实际检测／用途 |
| --- | --- |
| 图片理解 | 上传应用生成的测试图片并校验结构化分析；用于图片资料建议和视觉问答 |
| 视频采样帧 | 上传带时间说明的多张测试图片；用于视频片段采样理解 |
| 文本生成 | 文本请求；用于基于已有分析回答问题 |
| 结构化输出 | 校验标题、说明、标签 JSON；不强制服务实现 JSON Schema 模式 |
| 文本向量 | 独立调用 `/v1/embeddings`；用于分析正文与查询编码 |

勾选能力后，模型立即进入相应用途的候选列表，无需先保存或检测。可分别选择默认媒体理解、文本生成和文本 Embedding 模型，再保存；候选旁显示未保存、待检测、已检测、服务停用或未允许传输状态。执行任务前仍须检测实际使用的能力，并启用服务及传输许可。“文本生成”默认“与媒体理解相同”，也可独立选择文本模型，指文字输出，不是语音合成。允许多种能力重叠、一个服务多个模型，以及生成和向量来自不同服务。取消模型所需的能力时，会解除对应默认用途绑定。

高级选项中的“单次请求最大输出 Token”是发给服务端的生成预算，不是模型的上下文窗口。可填写 `384000` 等模型支持的值，也可留空以省略该参数、使用服务端默认值；Lap 不设置 8192 的统一上限，具体容量由服务端校验。新建模型的 2048 是默认请求预算，不表示模型只能输出 2048 Token。标题、说明和标签的结构化业务字段仍分别校验长度，媒体问答不会再因统一的 64 KiB 回答限制被拒绝。

批量任务还需要勾选服务的批量传输许可。修改地址、密钥、Model ID 或处理参数会使相关检测失效，重新检测后才能调用。更换默认用途不会修改已提交任务的模型快照。

## Embedding 的服务与模型边界

Embedding 使用独立接口，但同时有服务和模型两层配置：

| 层次 | 配置内容 |
| --- | --- |
| 服务 | 基础地址、API Key、服务是否实现 `/embeddings`、启用状态与传输许可 |
| 模型 | 该接口接受的 Model ID、文本／图片等输入能力、向量维度、模型版本与查询编码规则 |

[OpenAI 官方 Embeddings 接口](https://developers.openai.com/api/reference/resources/embeddings/methods/create/)要求请求包含 `model` 和 `input`，标准 `input` 是文本或 token 序列；返回浮点向量，与聊天接口的文字输出不同。例如：

```http
POST /v1/embeddings
Content-Type: application/json

{"model":"text-embedding-3-small","input":"湖边散步的照片"}
```

因此，服务实现 `/embeddings` 不代表其所有聊天模型都能生成向量，也不应为所有 LLM 勾选“文本向量”。应添加服务实际提供的 Embedding Model ID，再检测这一能力。服务只有向量接口时也可以单独配置，不需要聊天接口。

“OpenAI 兼容”也需要按接口核对：[阿里云文本 Embedding](https://www.alibabacloud.com/help/en/model-studio/text-embedding-synchronous-api)提供兼容的文本接口；[多模态 Embedding](https://www.alibabacloud.com/help/en/model-studio/multimodal-embedding-api-reference)有其输入与接口约定，不能只凭支持聊天或文本向量就推断图片／视频向量也兼容。Lap 当前通过文本 Embedding 编码已有媒体分析和搜索查询，不直接给原图／视频生成多模态向量。

## 使用入口

- **单张图片／视频**：右侧信息面板展开“媒体理解”，点“理解媒体”。分析独立保存；可分别采用标题、说明和标签。说明写入图库 `comments`；不改文件名、EXIF 或原媒体。
- **标签**：默认只匹配已有标签并追加关系。需要新词时显式勾选“允许创建新标签”。忽略的字段按媒体来源版本保留，重新理解同一来源也不会自动恢复。
- **当前媒体问答**：在同一面板输入问题。默认使用已有分析，回答带证据编号。需要像素细节时勾选“复核画面”，本次才再次发送图片或选中的视频采样片段；支持取消请求。
- **选中／全部媒体**：多选面板的“媒体理解”区域可提交选中媒体或全库可见媒体；自然语言搜索页也有全库入口。先预检，明确选择分析、生成向量、填充空标题／空说明或追加标签。
- **只补建向量**：选择“仅为已有分析补建向量”。不重新解码或上传原媒体，可用于后配 Embedding、切换向量模型，以及重试向量阶段失败。
- **自然语言检索**：搜索侧栏选择“自然语言”，输入描述。结果进入原有媒体列表；可选择已配置的 Embedding 和相册范围。视频匹配保留时间段，可跳转播放。
- **任务**：媒体详情里的“任务”或批量面板可查看逐项结果、暂停、继续和重试失败项。关闭面板不停止任务；退出应用后，未完成任务显示为暂停，可显式继续。

仅配置生成模型也可以理解媒体、生成资料建议和问答。Embedding 未配置时，向量生成与自然语言向量检索不可用；原有分析保留，之后可以直接补建索引。

## 数据与执行边界

图片按 EXIF 方向解码并缩放至最大 1280 像素；超过 8000 万像素的解码拒绝执行。视频按最长 60 秒分片，每片取 3 张带原片时间的帧，逐片保存，不宣称完整覆盖或精确事件起止；视频最长 24 小时。云端占位原件不会为分析自动下载。

分析 JSON 为 `title`、`description`、`tags`；文档编码为标题、说明、标签三行文本。向量做 L2 归一化，按余弦相似度检索。索引身份包含服务地址、远程模型、声明版本、维度和查询编码规则，和 CLIP 索引隔离。更换默认 Embedding 后应补建对应索引；原索引仍保留，可选择原来的有效模型继续查询。服务端实际换权重而不改别名无法自动识别，需更新模型版本并重建。

检索首版使用 SQLite 流式精确匹配，内存保留有限候选，不为查询读取原媒体。最多返回 100 个片段，同一媒体保留最佳片段排名；尚未引入大规模 ANN 加速。问答最多使用 12 条当前片段分析作为证据，详情中的视频片段选择决定本次范围。

每次写入检查图库、可见性与来源版本；采用建议使用事务并比较原标题、说明和标签快照，避免覆盖并发人工修改。分析、向量、任务和问答存入独立的 `media_ai_` 表，随图库数据库备份；服务配置随应用设置备份，密钥需要在新机器重新输入。

当前接入 Chat Completions 和标准**文本** Embeddings。不含 Responses、Messages、原媒体多模态 Embedding，或 Lap 管理的 Mage／Qwen 下载及本机推理环境。自建模型服务可使用 [部署脚本](../scripts/ai-server/README.md)，模型实际能力和显存需求仍需在目标服务器验收。
