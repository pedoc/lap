# 结构化组合筛选

在照片列表工具栏点击“组合筛选”，或进入“搜索 → 组合筛选”。条件查询当前图库的可见照片，不沿用此前侧栏的人物、目录或文字搜索范围；需要限定来源时，添加“相册”或“集合”条件。

- 可组合日期、地点、人物、标签、评级、收藏、筛选标记、文件类型、文件名、相机和镜头等条件。
- 支持“全部满足／任一满足”及嵌套分组，例如：`2025 年拍摄 且（人物 A 或人物 B）且评级至少三星`。
- 人物、物体和图片文字条件使用已有标注／识别索引。普通筛选不要求配置语义模型，不进行自然语言解析，也不自动识别或上传原图。
- 应用前可预览匹配数量与照片；应用后左侧展示条件，列表沿用现有排序、分组、地图、分页和多选功能。
- 物体、OCR 条件可展开列表中的“AI 索引状态”查看覆盖情况；未识别不等于没有该对象或文字。手动启动识别仍沿用原有确认流程。

“修改筛选条件”打开独立草稿，取消不会改动已应用条件。“清空条件”恢复当前图库的可见照片。切换到“文字搜索”保留本次会话的组合条件；切换图库或重启软件会清除临时条件。

需要长期使用时，点击“保存为智能相册”，填写名称后确认。新相册与临时筛选独立，可以继续修改各自规则。筛选及保存相册不移动照片，不修改原文件或其元数据。

## 验证边界

组件回归覆盖查询参数、嵌套条件、临时草稿、切库失效、文字搜索切换、保存相册，以及查询计数／分页／时间线／分组使用相同条件。真实 Tauri 窗口的点击与大图库交互仍需实机验收。
