# 媒体类型、隐藏与最近删除

## 媒体类型

图库左侧提供照片（包含 RAW）、视频、RAW、实况／动态照片、RAW＋JPEG 配对和 GIF 图片入口，支持数量显示、排序、照片分组和地图。分类可以重叠。GIF 仅按格式分类，不声称识别所有动画；截图、人像模式、全景、连拍等没有可靠元数据时不会推断。

## 已隐藏

照片或多选图片右键选择“隐藏照片”，确认后保留原文件、评级、标签、人脸标注和位置数据。隐藏项目不进入普通查询、搜索、智能相册、地图或 AI 聚类；已有相册／人物封面也会失效，改用可见照片。实况／RAW＋JPEG 的配套文件一起隐藏。

“图库 → 已隐藏”可只读浏览原图、RAW 和视频、批量取消隐藏，也可直接移入最近删除。隐藏不是加密，资源管理器仍能访问原文件。隐藏照片恢复后仍为隐藏状态；取消隐藏并不绕过图库的其他文件类型／目录过滤规则。

## 最近删除

普通照片删除默认移入软件管理的 `.lap-trash/<操作编号>/`，位于原图库磁盘。优先使用同盘硬链接和移除原路径；不支持硬链接的文件系统使用不覆盖目标的复制、校验后移除原路径。复制失败或磁盘空间不足时保留原文件，不能自动降级为永久删除。软件扫描不会导入回收区。

评级、标签、人工人脸标注、缩略图和集合关系随原图库记录保留。实况照片、RAW＋JPEG 和 Apple AAE 旁文件作为一组处理；恢复保留原记录 ID，可选择原位置、整组重命名或指定图库目录。磁盘离线、文件内容变化或目录重定向时停止并给出错误，任何模式都不覆盖现有文件。

在“图库 → 最近删除”选择本页项目后恢复或永久删除。永久删除要再次确认，只清理登记且校验通过的回收文件，不删除同名的新原文件，也不自动按天数清空。普通删除对话框仍可显式勾选永久删除，但不会记住并自动默认这个危险选项。

文件系统操作前先持久化恢复记录。进程中断后，未完成的移入／恢复仍显示在最近删除，可重试恢复；永久删除开始后只能继续清理，不能把不完整的组合恢复成完整照片。请勿自行改动回收区；恢复区内的文件被修改会阻止自动操作。

有尚未处理的最近删除记录时，相关目录的转移／删除、图库移除和图库数据库删除会被阻止，以免失去恢复元数据。文件夹本身的删除仍使用原来的系统回收站流程；本页管理的是照片及其配套文件。

## 恢复策略与冲突处理

在“最近删除”选中项目，点击“恢复”后先选择策略并预检，确认前可查看每组原文件名与最终路径：

- **原位置**：保留原名。文件、目录或其他图库记录占用目标时拒绝恢复；即使新文件内容相同也不会认领或覆盖。
- **冲突时整组重命名**：原位置无冲突时保留原名，否则 RAW、JPEG、视频与 AAE 同时使用同一编号，例如 `photo (restored 1).dng` 和 `photo (restored 1).jpg`。
- **指定图库目录**：选择已有相册根目录或输入其现有子目录，组内成员恢复到同一目录；冲突时同样整组加后缀。允许跨已登记相册／磁盘，不允许未登记目录；需要先把其他目录添加为相册。组内同名成员无法放入同一目录时，请改用原位置。

预检失败的组会逐项列出原因，只确认预检成功组。预检不移动文件，也不保留目标位置；执行前再次校验；尚未开始的组可能调整自动后缀，无法安全恢复时停止，不会覆盖文件。

恢复计划和逐成员进度先持久化。每个文件复制到目标目录的独立暂存文件，校验并落盘后，以不覆盖方式原子转为最终名称；整组成员复制、校验并提升成功前保留回收来源。因此需要额外可用磁盘空间，不足时保留来源并报告错误。恢复不改写媒体或旁文件内容，也不生成新的照片记录；原评级、标签、集合及人工人脸标注保留，原来隐藏的照片仍为隐藏状态。

中断后再次恢复会沿用已保存的目标与编号，不重新应用新策略；界面预检会标明继续已有计划。暂存文件只有在文件身份与登记信息一致时才会清理重试，无法证明归属的文件不会删除。在不提供稳定文件 ID 的文件系统上，“文件已转为最终名称、进度尚未持久化”这一极小中断窗口不能自动认领，需人工核对；不能仅凭相同内容推断归属。未完成计划的目标也受扫描与目录移除保护。

独立恢复清单同时保留原目录身份与最终目录身份；恢复旧数据库时可核对并回放已完成的重命名／迁移；目标相册未登记或身份不同会报告核对问题并保护扫描清理，不强行绑定，也不妨碍查看其他恢复记录。真实桌面、exFAT／网盘及 Linux／macOS 仍待实机验收。

## 后台任务、停止与重试

单图／多选／重复项的普通删除、已隐藏项目的回收，以及最近删除中的恢复和永久清理，都提交为后台媒体任务。窗口右下角显示阶段、已处理／成功／失败／跳过数量、当前文件组和当前文件的校验／复制字节进度。字节进度会随文件和阶段重新计数，不代表整库总大小。等待期间可以继续浏览、搜索或切换视图，不会一直占用全局图库写锁；同一图库同时只接受一个媒体任务，冲突的磁盘改名、转移或删除操作会拒绝执行，而不是长时间阻塞界面。

点击“停止任务”是请求在安全边界停止，不是回滚：已完成的组保留结果，未开始的原文件保持原位，半完成组保留登记与恢复清单。校验与复制每 64 KiB 检查停止请求；系统正在执行的磁盘／网盘 IO、同步落盘和最终清单／数据库提交不能强行打断，因此可能暂时显示“正在安全停止”。不要用结束进程来替代正常停止。

任务停止后可“重试未完成项”，只处理失败、取消或尚未开始的项目，不重新执行成功项；已经开始恢复的组沿用原路径与编号。曾创建安全副本但尚未移除原路径时，只能凭登记的原文件身份继续；同名同内容的新原文件也不会被删除。不提供稳定文件 ID 的文件系统遇到归属不明时需要人工核对。无法证明归属的临时文件不会自动清理。

任务面板保留本次软件会话中至多 16 条任务记录，每次请求最多 10 万项；失败计数与重试范围保留全部未完成项，详细错误最多列出前 200 项。面板只显示通用计数，不广播私有路径；在“已隐藏”或“最近删除”解锁后才能查看详细错误、重试已登记的私有回收组。轮询进度不会延长应用锁的闲置期限；锁定不撤销已经接收的文件操作。

切换图库会停止旧任务的剩余工作；连接固定到原数据库，旧响应不会填入新图库。删除任务使用的图库／数据库前必须先停止任务。重启软件不会恢复任务面板历史，但文件组清单仍持久化：最近删除中的“移入中断”可点击“继续移入最近删除”或选择恢复；“恢复中断”继续原恢复计划；“永久删除中断”只能继续清理。尚未登记／未开始的文件仍在原位置，可以重新选择。崩溃遗留且无法确认身份的暂存文件保留供人工核对，不假装已经清理。

最近删除的分页和增量刷新仅读取数据库及**上次完整核对报告**，不会反复读取历史恢复照片。启动图库、恢复数据库和扫描清理前仍核对恢复清单；也可在最近删除点击“重新核对恢复清单”，作为可取消的后台任务运行。文件操作本身始终重新校验路径、归属和内容，不会因报告缓存而跳过保护。所有过程都在本地执行，不上传原图，不写回 EXIF／IPTC／XMP。

## 备份与独立恢复清单

每个回收组在 `.lap-trash/<操作编号>/` 保存不可变、带版本的 `recovery-*.json` 清单。文件移动前必须成功写入；恢复／永久删除的完成记录在数据库提交前持久化。清单只是软件状态与身份信息，不会改写原媒体 EXIF／IPTC／XMP。

数据库备份同时打包恢复清单，但**仍不包含原图、视频或回收区媒体本体**。跨电脑迁移必须另行备份原图库磁盘。数据库副本仍可能引用同一套物理文件，不能把两个数据库副本当成两套独立媒体。

启动图库、打开最近删除以及恢复数据库时核对清单：能够确认身份的旧记录自动恢复登记，不移动媒体；身份不一致、清单损坏或无登记文件只报告并阻止扫描清理，不把恢复标注强行套到另一张照片。报告会在最近删除显示；`review_required` 项目暂不允许自动恢复或永久删除，需要先人工核对原文件与数据库来源。

## 私有区只读查看

点击“已隐藏／最近删除”的缩略图或“只读打开”进入查看器；没有缓存缩略图时仍可尝试打开原媒体。左右方向键或上一项／下一项按钮跨分页浏览，Escape 关闭。原图支持滚轮／± 缩放、拖动及 0／适合窗口复位，不提供编辑、外部应用打开或删除动作。

RAW 支持内嵌预览、本地渲染和自动增亮；RAW＋JPEG 及实况照片可切换登记的配套 JPEG／视频。视频沿用软件的本地播放与 FFmpeg 兼容缓存能力。特殊图片依赖本地解码器，不调用在线转换、AI 或自动上传；解码失败保留 RAW 选项，便于更换预览策略。

后端按当前图库、私有页面、文件 ID 和回收组解析来源，不接受前端传入的任意文件路径。最近删除仅读取完整、已登记且内容校验通过的回收副本；不会把原位置的同名新文件当作旧照片。中断、部分清理或待核对的回收组拒绝读原文件，并给出状态诊断。

读取／解码失败时显示详细错误；如有旧缩略图，明确标注“仅显示已有缩略图”，不把它当作原图可用。切图库、退出页面、取消隐藏、恢复、清理或收到状态变更通知时关闭／失效查看，延迟返回不能重开旧照片。应用锁是可选的软件访问限制，原文件、数据库和派生缓存仍不加密。

## 私有区应用锁

进入“已隐藏”或“最近删除”，点击顶部“应用锁设置”可启用全局密码；默认不启用，不改变原有文件状态。密码为 8–128 个字符，可以设置 1–60 分钟无操作自动锁定（默认 5 分钟），以及主窗口失焦锁定（默认开启）。修改密码、调整策略或关闭已启用的锁都需要当前密码。

启用后，重启软件、退出私有区、切换图库、点击“立即锁定”或会话过期都会重新锁定。两种私有页面之间切换可以沿用当前许可；切换图库不能沿用。正常操作可延长闲置期限，后台轮询和视频读取不延长期限。密码输入在提交、切换页面或锁定后清空，解锁令牌只保存在内存。

后端校验私有列表、缓存缩略图、原图／RAW、视频、取消隐藏、移入最近删除、恢复和永久清理的权限。临时预览票据不包含实际路径，锁定／换库后撤销，响应禁止持久缓存；Linux 视频沿用本地 HTTP 播放，但使用受校验的票据，不再使用任意路径 URL。旧的异步结果不能重新显示已经锁住的照片。锁定不会撤销已经接受的文件操作，以免中断恢复、造成不完整的文件组。

应用数据目录中的 `private-lock.json` 只保存随机盐和 PBKDF2-HMAC-SHA256（60 万轮）校验值，不保存明文密码；损坏或无法读取时拒绝私有访问，不自动降级成未启用。错误密码连续 5 次后等待 30 秒，切换图库不会重置该限制。

**这不是加密或安全保险库**：原图、数据库、回收区和转码缓存仍可被系统账号访问，已查看或复制的内容无法撤回；不能抵抗调试工具、插件或对程序／配置的修改。忘记密码无法找回；作为系统账号所有者，可退出软件、备份并移走应用数据目录中的 `private-lock.json`，重启后重新设置锁。此操作不会删除照片，但会移除软件访问限制；因此不能把应用锁当作文件加密。
