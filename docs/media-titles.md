# 图片标题

在图片信息面板的“标题”一行点击“添加标题”即可编辑。Enter 保存，Esc 取消；“清除标题”后保存可恢复为未设置状态。标题最多 256 个 Unicode 字符，不能包含换行和控制字符，可以使用与文件名规则不同的标点。

- 独立看图窗口点击顶部“信息”图标或按 `I`（也支持 `Ctrl+I` / `⌘I`）打开右侧信息面板，可查看文件、EXIF、地点和识别结果，并直接编辑标题。对比模式跟随当前选中的图片；标题草稿未保存时，切图、切换对比图片、关闭面板或窗口均受到保护。打开面板会暂停幻灯片。
- 标题仅保存在当前图库数据库，不重命名、不修改图片或 EXIF。
- 缩略图的“显示名称（标题优先）”、首页、独立看图窗口和拼图文字优先显示标题；未设置时回退真实文件名。“文件名”标签仍可单独选择。
- 普通搜索同时查询标题、文件名和备注；智能相册支持标题包含、不包含、为空、不为空。标题排序独立于文件名排序，支持中文拼音和数字自然顺序。
- 标题是用户资料，不从原图描述或 AI 提示词自动生成。重扫、元数据刷新、隐藏和回收站恢复不会覆盖标题；图库备份包含标题。
- 多窗口更新会就地同步。如果另一个窗口已经改过标题，保存会保留当前草稿并提示冲突，可以重新载入后编辑，不会静默覆盖。
