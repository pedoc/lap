# 缩略图重新生成与 HEIC 缓存修复

## 入口与作用域

图片右键菜单提供“重新生成缩略图”，支持单张及多选 JPEG／HEIC／PNG／RAW 等已入库图片。文件夹及相册根目录右键有同一入口，可选择是否包含子文件夹。当前选中项、图库 ID 和文件夹 ID 会固定在请求中；空选择、无效 ID、混合视频选择不会变成全图库重建。

任务逐张处理并显示成功／失败／跳过计数，可以停止。停止等待当前图片完成，保留已完成的缩略图；切换图库停止剩余任务，队列不会写入新图库。不会额外扫描文件系统或导入未入库文件。

## 安全与显示刷新

只替换派生缩略图，不修改原文件、标签、评分或人脸标注。离线源文件跳过且保留已有缓存；显式重建在成功解码后才提交，新解码失败不删除旧缓存。后台自动生成和显式重建使用同一逐文件锁。完成后仅通知相关图片刷新缩略图，主照片像素、视口和选中状态不整页重载。

## HEIC 缓存与原生构建

HEIC／HEIF／HIF 缓存采用带解码签名的 `h2` 键。签名覆盖原生解码源代码、构建策略和 Rust FFI／颜色转换代码；旧在线缓存重新生成，离线图库仍复用旧缩略图，JPEG 等其他格式不因该签名失效。原图未改变也不再永久复用旧花屏 JPEG。RAW+HEIC 配对的缓存键同样包含解码签名。

libde265 不再仅因静态库存在而跳过构建；源代码或编译策略签名变化会重新配置并构建，MSVC 继续使用已验证的 `/O1`。解码返回警告时不将损坏结果当成功缓存，而进入现有回退链；回退能力仍取决于实际 FFmpeg 版本，旧版本不保证支持所有 HEIC。

仅检查 JPEG 头尾不能判断画面是否正确，因此原生验证使用用户明确授权的 HEIC 样本与独立解码参考，确认非花屏结果。测试样本与诊断图片只放在忽略的 `src-tauri/target`，不提交到仓库。
