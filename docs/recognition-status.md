# 识别状态提示

人脸、图片文字（OCR）和对象识别的后台状态显示在左侧对应入口右上角，不在右下角弹出识别状态卡或完成提示。

- **闪动绿点**：正在准备、等待资源、识别、聚类或停止。系统启用“减少动态效果”时绿点保持常亮。
- **黄点**：任务失败、部分照片识别失败、意外中断，或当前图库的自动识别因错误暂停。任务仍在处理但已有失败时也显示黄点，悬停可查看当前进度。
- **没有状态点**：当前没有任务和待处理问题。成功完成、正常主动停止、未识别照片尚未安排任务，以及没有错误的手动暂停不会显示故障点。

鼠标停留或用键盘聚焦入口时，提示中显示阶段、任务范围、已处理数量及错误。准备清单与识别使用各自的进度；尚未确定总数时不显示虚假的百分比。提交请求但尚未收到本次任务状态时显示等待，不沿用上一任务的范围或 100% 进度。提示会随任务更新，停留期间保持显示，移开／失焦或按 Esc 关闭；普通按钮提示关闭时仍可查看任务状态。

人脸、OCR 和对象识别分别排队，可同时运行。某类正在分析时，仍可对选中的照片发起该类识别或重新识别；手动选图任务在当前照片处理完后优先于后台批次执行。多个手动请求按提交顺序处理，完成后后台任务继续；已保存且仍有效的结果会复用。侧栏提示会显示排队数量及手动优先状态，排队回执不会覆盖当前任务的进度。OCR 局部识别与整图文字识别共用 OCR 队列。

点击入口仍进入原有功能页，可查看详细任务记录、停止、继续或重试。显示、隐藏提示不会启停识别，也不会更改已有结果。切换图库时清除旧库状态，迟到的进度不会覆盖新库；对象任务可恢复已有中断记录，人脸仅恢复当前运行信息或当前应用会话中已保存的诊断。

停止指定任务只取消该请求；切换图库会取消旧库的识别和等待任务，等待当前不可中断的单张处理结束后完成切换。模型及运行时配置变更仍要求所有识别任务空闲。并行任务共用机器的内存、显存和计算资源，实际速度取决于硬件。
