## 类别与结果契约

首批模型均提供 COCO 80 类，不支持任意概念、车牌、票据分类或对象身份。类别键由标签集命名空间、版本和原始类别 ID 组成；相同命名空间版本不允许声明冲突映射。未知第三方类别保留原始名称，不强行套用穷举词典。

检测结果使用原图归一化坐标，保存模型／适配器／参数／标签集指纹。分数不跨模型比较，不是校准概率；达到候选或数量上限会标为不完整，不能把截断结果当作确认未检出。GPU 自动策略和显式设备选择沿用既有运行时，自动执行失败可回退 CPU 并显示原因，显式 GPU 不静默更换。

## 使用入口

1. 在「设置 → AI 模型 → 对象检测」选择全局模型、下载权重，并配置设备、置信度、同类 NMS 与输出上限。参数按模型保存。
2. 打开「对象」侧栏处理未识别照片，或从单张／多选照片、图库目录和文件夹右键菜单启动指定范围。任务可停止，已完成照片逐张保存；失败项可单独重试。
3. 侧栏按识别状态或类别查看照片，选择类别后可设置每张至少几个。默认只展示出现过的类别，也可展开全部支持类别。缩略图不重复覆盖当前分类标签。
4. 照片信息面板可定位原图对象框，确认、更正类别、忽略误报和恢复原项。框随原图缩放／旋转，保持屏幕描边宽度；预览比例不匹配时隐藏框并提示。
5. 智能相册新增对象状态、类别、数量规则及模板，可组合其他查询条件。规则只读取已保存结果，不会暗中启动识别。

人工修订保存来源快照和版本，不按重识别后的行号套用；切换模型／重新检测仍保留人工结果。移除人工修订后才使用当前模型结果。改类后不继承原类别的机器分数。精确数量、否定类别与零数量要求结果完整、来源模型支持该类别；失败、未识别和不支持不能等同于“没有”。

## 验证边界

两份固定权重已完成大小／SHA-256 校验，并通过软件共用 Rust 下载通道实际安装（RT-DETR 使用显式本机代理复测通过，远端此前出现过响应中断）。CPU 和 DirectML 原生推理均已验证，GPU 验证包含实际算子事件，不只是注册执行提供者。结果存储、来源失效、人工保护、截断／否定规则、前端请求竞态和组件渲染已有回归测试。

当前环境未连接到可操控的桌面／浏览器实例；原生窗口布局、键鼠操作和长任务交互仍需实机验收。构建、服务端组件渲染和推理测试不替代这部分验收。
