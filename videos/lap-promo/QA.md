用户追加的 DLNA 投屏独立占 f720–830；原有功能镜头时长保留。片尾为 f831–996，只有品牌与产品主张，没有网址或二维码。

## 已验证

- `npm run lint`：ESLint 与 TypeScript 通过。
- `npm run verify:timeline`：八个独立镜头连续、无缺帧；所有切点符合音乐实测节拍。
- `npm run verify:delivery`：主片和无 BGM 版为 3840×2160，分享版为 1920×1080；均为 997 帧、30fps、H.264 / yuv420p / BT.709、48kHz 立体声 AAC。
- 带 BGM / 无 BGM 两版复用同一已编码图像流，视频包 SHA256 相同。
- 三个 SFX 探针在编码产物中的起点偏移均为 0 帧；切点与真实音频瞬态的最大偏差约 1.15 帧。原双声道解码采样峰值约 -2.53dBFS，独立审查的真峰值约 -2.5dBFS、综合响度 -16.5LUFS，没有削波。单声道下混分析峰值 -0.24dBFS 单独记录，不混用两种口径。
- 原生界面取自仓库已记录来源的公开演示截图。DLNA 是明确标注的效果示意，不是电视实机录像。
- 已检查新投屏段、无链接片尾及完整编码九宫格；早期识别段对齐和小字问题已修正。

详细机器证据见 `out/qa/delivery-verification.json`，独立视觉审查见 `out/qa/independent-review.md`。原始 WAV 音效轨保存在 `out/qa/nobgm-sfx.wav`，不是从混合配乐中分离的音频。
