这是供确认的独立交互原型，不连接模型，不保存真实会话，不修改资料库。设计说明放在预览页下方，不出现在截图中。示例照片来源见 [SOURCES.md](assets/SOURCES.md)。

## 本轮收敛

- 只有图库右下角、查看页工具栏两个入口；取消独立侧栏聊天入口和信息面板旧入口。此改动目前仅体现在设计稿，尚未修改业务代码。
- 两个入口打开同一个非模态对话框。可以拖动标题栏、右下角缩放或展开／还原；背景图库仍可浏览。
- `@` 候选按“本会话／当前资料库”查找，重名媒体展示文件夹；选中后成为当前草稿中的文件引用，同时加入本轮。发送前以“本轮引用”名单为准，历史回答来源固定。
- 查看页恢复已有会话时显示“当前查看”条，明确选择加入本轮或新建会话；切换图片不自动替换附件。
- 会话顶部选择模型，默认继承既有媒体理解模型，只影响后续请求。原服务接入、模型能力和默认用途配置保持。聊天不选择 Embedding；纯文本模型只用于已有分析模式。
- 批量理解、补建索引及任务状态收进会话内部的任务入口；标题／说明默认仅填空白、标签追加去重，先预览后应用。

可试用：聊天按钮打开／关闭、标题栏拖动、右下角缩放、模型菜单、`@` 候选（↑／↓、Enter／Tab、Esc）和引用片段插入。按钮发出的提示均为原型反馈。

需要重新导出 PNG 时，在 Windows 上用 Node 24+ 运行：

```powershell
node design/media-chat-preview-v1/render-preview.mjs
```

脚本使用已安装的 Microsoft Edge，无需额外依赖，退出时关闭临时浏览器和 HTTP 服务。运行报告 `*-report.json` 不纳入版本控制；`07-resized.png` 是单独交互验收时导出的状态图。
