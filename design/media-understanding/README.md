## 设计决定

- 媒体理解在模型管理中以 VLM 独立成类，与人脸、OCR、对象识别并列；语言生成以 LLM 单独配置。
- 图片与视频可以选择同一个媒体理解模型；设置只展示所需用途和处理参数。
- 查看器工具栏提供“理解”，在右侧信息面板中展示已保存分析、建议和当前媒体问答。
- 分析产物独立保存；只有采用建议或明确提交批量填充任务时才写正式标题、说明。
- 多选与全库任务复用同一处理流程，默认仅填空白，保存时保护并发人工编辑。
- 模型条目、任务数字、下载状态和视频时间均为示例，不代表已适配、测试或运行结果。
